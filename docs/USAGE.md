# Shelf 使用与安装指南（中文）

> 完整的安装步骤、全部功能说明和常见问题。英文简介见 [README](../README.md)。

---

## 一、这是什么

**Shelf** 是一个原生的 macOS 文件收纳工具：把文件拖进不同的「模块」收纳架，
它只记住文件的位置（快捷方式），**绝不移动或修改原文件**。双击直接打开，
一键跳回文件在 Finder 里的位置。

## 二、系统要求

- macOS 15.0 或更高版本
- Apple Silicon 和 Intel 芯片均支持（Universal 二进制）

## 三、安装（3 分钟）

1. 从 [Releases](../../releases) 下载 `Shelf-vX.Y.zip` 并解压
2. 把 `Shelf.app` 拖进「应用程序」（Applications）文件夹
3. 首次打开——重要！App 未经 Apple 公证，会被系统拦截，按顺序尝试：

   - **方法一**：在「应用程序」里 **Control 键 + 点击** Shelf → 打开 → 再点一次「打开」
   - **方法二**：系统设置 → 隐私与安全性 → 页面底部点 **「仍要打开」**
   - **方法三**（终极）：终端执行

     ```bash
     xattr -cr /Applications/Shelf.app
     ```

   之后打开就与普通 App 完全一样。

## 四、功能说明

### 1. 模块管理

- 左侧栏 = 模块（收纳架）。**+** 新建，**−** 删除，**✏️** 重命名
- **双击模块名**可以就地重命名（回车确认 / Esc 取消）
- 右键模块 → **模块设置…**：自定义图标（60+ SF Symbols）、强调色、
  边框色、背景色、以及用于自动分类的关键词
- 每个模块有独立的配色，会体现在标题栏徽章和侧边栏选中态上

### 2. 收纳文件（快捷方式）

- 从桌面或 Finder 把文件拖进某个模块 —— 只创建快捷方式，**原文件原地不动**
- 按住文件磁贴**拖到左侧另一个模块上** = 直接移动归属
- **双击**磁贴 = 打开原文件
- 右键磁贴 → 在 Finder 中显示 / 彩色标签 / 备注 / 移动到… / 移除
- 详情面板里可以复制文件的完整路径

### 3. 搜索（⌘F）

按 **⌘F**（或点工具栏搜索框），按文件名和备注实时过滤当前模块。
Esc 清除，切换模块时自动重置。可与标签筛选叠加使用。

### 4. 自动分类

把文件拖到**右侧面板**，Shelf 会自动判断归属：

- **首选**模块（带置信度环 + 命中理由）+ 最多 3 个次选
- 点卡片即可归档；勾选「记住这条规则」后，同类文件下次优先归入
- 判断依据：文件名 / 路径与模块关键词的匹配（纯本地、离线可用）
- **AI 增强（可选）**：设置 → AI 增强 → 填入 DeepSeek 等 OpenAI 兼容接口的
  API Key。开启后本地判断立刻显示，AI 结果随后叠加（卡片上标 ✨）

### 5. 临时分组（1–24 小时自动清理）

点侧边栏底部的 **🕐** 创建：

- 保留时长可选：1 / 2 / 4 / 8 / 12 / 24 小时
- 侧边栏实时显示剩余时间，最后 10 分钟变红
- 到期后该分组及其中的快捷方式自动删除，**原文件不受影响**
- 右键临时分组：立即清理 / 延长 1 小时 / 取消倒计时（转为永久）

### 6. 外观自定义

设置（⌘,）→ 外观：

- **全局背景色 / 边框色**：作用于窗口、卡片、分割线、输入框
- 留空则跟随系统深浅色自动切换

### 7. 全局呼出

- 默认快捷键 **⌥Space**（Option + 空格）随时呼出 / 隐藏 Shelf
- 可在 设置 → 通用 里更换；若被占用会自动回退到可用组合
- 菜单栏右上角有常驻图标，可快速跳转到任意模块

## 五、数据与隐私

- 所有数据保存在本机：`~/Library/Application Support/Shelf/shelf.json`
- 不联网（AI 增强关闭时）；开启 AI 后仅把文件名发送给你自己填的接口地址
- App 不包含遥测、不申请网络权限、不读写文件内容
- 备份 shelf.json 即备份全部数据；删除 App 不影响原文件

## 六、常见问题

**Q: 提示「已损坏，无法打开」？**
macOS 对未公证 App 的安全拦截，App 本身没有问题。终端执行
`xattr -cr /Applications/Shelf.app` 后正常打开。

**Q: 拖进去的文件会被移动吗？**
不会。Shelf 只保存书签；删除 Shelf 或删除条目都不影响原文件。

**Q: 原文件被我移动了怎么办？**
书签通常能自动追踪移动和改名；追踪失败时条目会标记「原文件已丢失」，
右键移除即可。

**Q: 如何卸载？**
把 Shelf.app 移到废纸篓；连同数据一起删则再删除上述 shelf.json 文件夹。

## 七、从源码构建

```bash
git clone https://github.com/Dannn2007/Shelf.git
cd Shelf
./Tools/build.sh      # swiftc 双架构编译 + lipo → .build/Shelf.app
./Tools/install.sh    # 安装到 /Applications/Shelf.app
```
